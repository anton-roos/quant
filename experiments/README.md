# Experiments

Experimental code, prototypes, and research implementations.

This directory contains non-production code used for:
- Testing new algorithms
- Exploring data processing techniques  
- Research and analysis
- A/B testing different approaches

## Guidelines

- Keep experimental code here, not in `src/`
- Don't import from experiments into production code
- Clean up old experiments periodically
- Document the purpose of each experiment
- Use subdirectories for organization

## Contents

- `classification/` - Classification-based prediction experiments
