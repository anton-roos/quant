# Notebooks

Jupyter notebooks for exploration, analysis, and documentation.

## Contents

- `forecast_v3.ipynb` - Example forecasting analysis notebook

## Guidelines

- Use notebooks for exploratory analysis and visualization
- For production code, move logic to `src/`
- Document notebook purpose in the first cell
- Keep notebooks clean - restart kernel before saving
- Use descriptive variable names
- Add markdown cells to explain analysis steps

## Running Notebooks

```bash
jupyter notebook notebooks/
```

Or use VS Code's built-in Jupyter support.
